# Автопул - Яндекс Карты 🚗

Страница компании "Автопул" на Яндекс.Картах (Саратов).

## 🔗 GitHub Репозиторий

**https://github.com/gorbacenkovitalij6-prog/avtopul-yandex-maps**

---

## ⚡ Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/gorbacenkovitalij6-prog/avtopul-yandex-maps.git
cd avtopul-yandex-maps

# 2. Установить зависимости
bun install

# 3. Запустить dev сервер
bun dev

# 4. Открыть http://localhost:3000
```

---

## 📋 Что нужно настроить:

### 1️⃣ Конфигурация компании
📁 **`config/company.config.ts`**

Измените все данные компании:
- Название: "Avtopul"
- Телефон
- Email
- Адрес
- Координаты карты
- Сайт

### 2️⃣ Логотип
📁 **`public/avtopul-logo.svg`**

Замените на логотип вашей компании (SVG или PNG)

### 3️⃣ Отзывы
📁 **`src/data/reviews.ts`**

Добавьте реальные отзывы Avtopul или удалите существующие

### 4️⃣ URL карты
📁 **`src/app/page.tsx`**

Обновите redirect на адрес компании Avtopul

## 🚀 Деплой на Netlify

1. Зарегистрируйтесь на https://netlify.com
2. Подключите GitHub репозиторий
3. Настройки:
   - Build command: `bun run build`
   - Publish directory: `.next`
   - Node version: 20
4. Нажмите "Deploy"
